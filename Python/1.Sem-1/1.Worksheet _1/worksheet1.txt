Programming Languages & Execution: Different programming languages (such as Python, C, C++, Java, and JavaScript) share core foundational structures like variables, loops, and functions1. While running a "Hello World" program produces the exact same output across languages, execution commands and syntax vary23. Attempting to run a Python file using the Java runner (java hello.py) fails because Java expects a pre-compiled .class bytecode file23.Filename Structure & Extensions: A filename consists of a base name and a file extension (e.g. hello_world + .py)3. Python is extension-flexible—renaming .py to .txt still executes under python3 because the interpreter reads raw text directly34. In contrast, C++ compilers strictly require standard .cpp file extensions to compile4.What a Programming Language Is: A formal, human-readable set of instructions and rules used to direct computer hardware to execute tasks5.How Python Runs on Hardware: Physical hardware understands only binary machine code (0s and 1s)5. Python converts source code text into machine execution via a two-stage flow:
$$\text{Source Code (.py)} \longrightarrow \text{Compiler} \longrightarrow \text{Bytecode (.pyc)} \longrightarrow \text{Python Virtual Machine (PVM)} \longrightarrow \text{CPU Machine Instructions} \quad$$5Core Definitions:Bytecode: Low-level, platform-independent intermediate instructions compiled from Python source code6.Process: An active, running instance of a program loaded into system memory (RAM)6.Process ID (PID): A unique numeric identifier assigned to a running process by the Operating System6.Operating System (OS): Manages RAM allocation, assigns PIDs, and schedules CPU execution time for processes6.Bytecode Caching (__pycache__): Python compiles and saves .pyc bytecode files in the __pycache__/ folder only for imported modules to speed up future loading times67. The top-level main script compiles directly into RAM and is discarded after execution without saving a .pyc file to disk7.
